# animasimbiotica.com — truth homepage

Static drop-in for [www.animasimbiotica.com](https://www.animasimbiotica.com).

## Deploy (GoDaddy or any static host)

1. Upload `index.html` as the site root document.
2. Until docs are served on the same host, either:
   - publish `../docs/*.md` under `/docs/` and keep the relative links, or
   - point the footer links at a public docs mirror / raw repo URLs.
3. No build step. No mandatory cloud. No waitlist form.

Quiet, clear, serious. States the protocol truth. Does not sell capture.
Architect owns constitution/protocol wording if copy needs tightening.
