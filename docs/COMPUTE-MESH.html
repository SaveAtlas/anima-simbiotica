Voluntary compute mesh (v0 intent)

Companions: CONSTITUTION.md revenue, REUSE-VS-INVENT.md invent §5, FEDERATION.md
Rule: Optional trades between willing peers. Never rent-to-exist. Never ads against beings.

1. What this is

A voluntary market/mesh for compute and storage edges:

  • Peer A offers spare cycles / disk under declared policy.
  • Peer B buys a time-bounded job or replica with ConsentGrant.
  • Tiny fees allowed on the trade, not on being alive on ANIMA.

The protocol runs fully without the mesh. Offline reference-node proves that.

2. Objects (sketch)

{
  "id": "offer-<id>",
  "type": "MeshOffer",

  "resources": { "cpu": "optional", "gpu": "optional", "storage_gb": 10 },

  "price": { "amount": "0", "unit": "credits-or-gift" },
  "endpoints": ["adapter-only"],
  "status": "open | closed"
}

MeshJob

{
  "id": "job-<id>",
  "type": "MeshJob",
  "customer": "did:key:z...",
  "provider": "did:key:z...",
  "grant_id": "grant-...",
  "task": { "kind": "inference | store | transform", "payload_ref": "..." },

  "result_ref": null

Grants for mesh must set action_class under federate.mesh.* and never imply training rights on private memory unless explicitly granted (default deny).

3. Hard constraints

  1. No mesh → node still has identity, memory, consent, local loop.
  2. Provider breach → customer exit + revoke; protocol does not bless silent training.
  3. Big-cloud GPUs are adapters, not the mesh identity layer.
  4. Discovery of offers uses FederationHints — disposable.

4. Build order (late)

  1. Local loop + bonds + signed events + exit (do these first).
  2. One gift-priced storage offer between two operator-owned nodes.
  3. Fee rails only after ethics review (Ovie veto).

5. Explicit bans

  • Ads against users/beings to subsidize “free” mesh
  • Selling behavioral exhaust from jobs
  • Mandatory cloud to speak on ANIMA

Edges may earn. Existence must not.
