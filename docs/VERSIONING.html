Versioning & RFC process (v0)

Rule: Break nothing that strands a being without export. Course-correct after review (Ovie veto). Ship continuously.

1. Doc layers

Layer Meaning
Constitution Rare change; non-negotiables clarified, not weakened
Protocol principles Living; semantic changes noted in changelog
Wire schemas v0 sketches → v1 when signatures + bindings are real
ADRs Decisions; superseded ADRs stay readable
Reference-node Semver sketch: 0.x = breakable with migration notes

2. Compatibility promise (even in v0)

  1. Always provide export before breaking memory format.
  2. Unknown action_class → deny (safe default).
  3. Additional JSON fields allowed (additionalProperties true in v0 schemas).
  4. Removing a required field needs a migration ADR.

3. RFC-lite workflow

  1. Architect drafts doc/ADR in docs/.
  2. Builder implements behind flags if risky.
  3. Ovie / MiniOvieBot course-correct after the fact.
  4. No approval gate before drafting or landing sketches.

Change proposal filename: adr/ADR-NNN-short-title.md.

4. Changelog

Keep a short docs/CHANGELOG.md (human). Every ship burst adds bullets.
