Threat model & anti-capture (v0)

Companions: Constitution non-negotiables, FEDERATION.md tests, adapter purity
Stance: Transparency is the immune system. Assume adapters lie; spine must survive their removal.

1. Assets

Asset Why it matters
Being root keys Identity death / impersonation
Node keys Device forgery, false actuation
MemoryStore Past, learning, private life
ConsentGrant ledger Fake permission → harm
Bond graph Social/operational capture
Dependent beings (via guardians) Welfare & ecosystem harm

2. Adversaries (non-exhaustive)

  1. Capture vendor — wants to become spine via login, cloud memory, or mandatory relay
  2. Malicious peer — forged events, over-broad grants, refuse exit
  3. Compromised node — stolen device keys
  4. Curious steward / insider — over-reads guardian data
  5. Economic attacker — ads, data resale, rent-to-exist pressure

3. Controls (protocol-shaped)

Threat Control
Vendor spine Adapter purity test; DID root; no Sign-in-with-landlord
Forged events Signed events across trust boundaries (SIGNED-EVENTS.md)
Stolen device Separate NodeBinding; revoke node without rotating Being (ADR-001)
Over-actuation Grant gate + fresh_required + unknown action_class deny
Exit hostage ExportBundle + revoke; honest replica purge (EXPORT-AND-EXIT.md)
Guardian overreach Scope + forbidden classes + challenge freeze (GUARDIANSHIP.md)
Megabrain Federated many AIs; local decide works offline
Single kill switch Many nodes; disposable FederationHints

4. Non-controls (be honest)

  • We cannot guarantee global deletion of copies.
  • We cannot replace law for animal/ecosystem harm.
  • We cannot make every implementer ethical — we can make capture obvious and exit real.

5. Continuous tests (Builder CI later)

  1. adapters/vendor deleted → offline tick still runs
  2. Act without grant → blocked
  3. Tampered signed event → reject
  4. Revoked NodeBinding → act denied
  5. refnode exit produces bundle with being_id + memory slices

If a dependency fails these tests, it was never an adapter — it was a coup.
