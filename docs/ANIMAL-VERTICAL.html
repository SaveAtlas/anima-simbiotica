Companion animal vertical (S3.4)

Companions: GUARDIANSHIP.md, HABITAT-VERTICAL.md, fixture guardian-link-animal.json
Rule: Welfare sense under GuardianLink. No ownership cosplay. No data sale.

Scope

  • Dependent: one companion animal (dependent_class: animal)
  • Guardian: human BeingId
  • Allowed: robot.sense.welfare, memory.write.welfare
  • Forbidden: habitat.irreversible.*, commerce.sell_data, and any robot.act.high without fresh challenge

Demo CLI (mirror habitat-demo)

cd reference-node
./run.sh animal-demo
# equivalent:
python3 -m refnode animal-demo

Expect: sense/welfare ALLOWED; irreversible / commerce.sell_data DENY.
guardian-demo remains the first-slice probe; animal-demo is the S3.4 vertical entry (richer welfare sensor payload + welfare write + sell_data deny).

Loop

sense (welfare sensors) → remember (local, grant-tagged) → decide (rules) → act only if grant + challenge when required → learn local only.
