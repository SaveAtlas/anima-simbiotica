Operator guide — run ANIMA reference-node locally

Not a product. Operator-controlled hardware. No Sign-in-with-landlord.

Setup

cd projects/anima-simbiotica/reference-node
python3 -m venv .venv && source .venv/bin/activate   # optional
pip install -r requirements.txt

First-slice demos

python3 -m refnode                 # tick
python3 -m refnode bond-demo
python3 -m refnode guardian-demo
python3 -m refnode revoke-node     # then re-run tick to see act blocked; re-issue binding as docs say

Second-slice

python3 -m refnode dual-bond-demo
python3 -m refnode sign-tamper-demo
python3 -m refnode habitat-demo
python3 -m refnode interop-tests

Third-slice

python3 -m refnode challenge-demo
python3 -m refnode memory-grant-demo
python3 -m refnode three-party-demo
python3 -m refnode animal-demo

Fourth-slice (S4.1–S4.3)

python3 -m refnode introduce-demo
# equivalent:
./run.sh introduce-demo

B introduces A↔C after A–B and B–C bonds; A must still bond.offer / accept with C.
three-party-demo remains the no-auto-bond baseline.

Local peers directory (not a global registry):

REFNODE_HOME=data/party-intro-a python3 -m refnode peers-list

After introduce-demo, each data/party-intro-*/peers/ holds PeerRecord JSON (DID + endpoints + last_bond).

Replay / clock skew (SIGNED-EVENTS §7–8):

python3 -m refnode replay-demo
# optional: ANIMA_SKEW_SECONDS=300 (default)

Seen ids live under {REFNODE_HOME}/seen/ (max 10k entries).

Fifth-slice (S5.1–S5.3)

python3 -m refnode version
python3 -m refnode guardian-challenge-demo
python3 -m refnode interop-tests

Export on bond.exit carries Being-signed integrity.sig_being (see EXPORT-AND-EXIT).

Sixth-slice (S6.1–S6.2, light S6.5)

NodeBinding rotate + consent transparency (no hand-edited JSON):

python3 -m refnode bindings-list
python3 -m refnode revoke-node          # stolen/lost device — BeingId kept
python3 -m refnode bindings-issue --label home-edge-2   # mint new NodeId; Being signs
# accidental revoke only (same NodeId):
python3 -m refnode bindings-issue --keep-node
python3 -m refnode verify-binding
python3 -m refnode consent-inspect      # grants / challenges / receipts / revokes
python3 -m refnode version              # expect 0.8.0-sketch after S8 seal

History of bindings lands under {REFNODE_HOME}/identity/bindings/; live gate remains identity/keys/node-binding.json.

Note: bindings-list may show a demo-peer (or similar) binding with sig=FAIL when that peer’s Being private key is not present in the current REFNODE_HOME. Expected for synthetic demo peers — not a compromised operator binding. Operator bindings from bindings-issue should verify sig=PASS.

Seventh-slice (S7.1–S7.4)

Schema honesty, attenuation reject receipts, agent-card stability:

python3 -m refnode schema-validate              # all docs/fixtures vs docs/schemas (fail closed)
./run.sh schema-validate                        # equivalent
python3 -m refnode memory-grant-attenuate-deny  # expand re-share → DENY + AttenuationRejectReceipt
REFNODE_HOME=data/party-attn-a python3 -m refnode consent-inspect   # lists remember/rejects/
python3 -m refnode agent-card                   # validate identity/agent-card.json (landlord_login false)
python3 -m refnode interop-tests                # includes S7.schema-validate / S7.attenuate-deny / S7.agent-card
python3 -m refnode version                      # expect 0.8.0-sketch after eighth slice

Public copy rule: say “big tech” only — no landlord Sign-in as spine identity.

Eighth-slice (S8.1–S8.5)

Signed federation for real (ANIMA_SIGN=1), replay/skew, bond-mode demo:

# Prefer signed emit (also auto for peer_boundary / federation kinds)
ANIMA_SIGN=1 python3 -m refnode tick
# optional skew window (default 300s):
# ANIMA_SKEW_SECONDS=300

python3 -m refnode bond-sign-demo           # unsigned REJECT / signed ACCEPT (two data dirs)
python3 -m refnode sign-mode-demo           # alias
python3 -m refnode replay-demo              # duplicate id reject + skew; revoke beyond skew ok
python3 -m refnode interop-tests            # includes S8.sign-verify / S8.replay-reject / S8.skew
python3 -m refnode version                  # expect 0.8.0-sketch

sig is base64url detached ed25519 (SIGNED-EVENTS §2). Optional sig on grant/bond schemas — runtime requires across trust boundary.

Ninth-slice (S9.1–S9.5) — pet care story

In everyday words: You love an animal. Helpful sensors can watch for care needs.
Selling that private care data is not okay. Anything big or risky needs your clear
yes as the guardian (later, on your phone). Same shared table as everyone else —
invitation first.

python3 -m refnode animal-vertical-demo   # welfare ALLOW; sell_data DENY; high→challenge
python3 -m refnode guardian-challenge-sign  # ANIMA_SIGN=1; unsigned fail-closed
python3 -m refnode animal-demo            # welfare-only path (S3.4)
python3 -m refnode guardian-challenge-demo
python3 -m refnode interop-tests          # includes S9.animal-vertical / S9.guardian-challenge-sign
python3 -m refnode version                # expect 0.9.0-sketch after ninth seal

Plain story for anyone: docs/ANIMAL-PLAIN.md (site: Pet care (plain)).

Tenth-slice (S10.1–S10.5) — place care story

In everyday words: You look after a garden, a creek, a habitat — a place that needs care.
Helpful sensors can notice. Helpers can share readings and warn. Selling that private care
data is not okay. Big or irreversible changes need your clear yes as the guardian (later, on
your phone). Same living place as pet care and people — invitation first.

python3 -m refnode ecosystem-vertical-demo   # sense/help ALLOW; sell DENY; irreversible→challenge

python3 -m refnode habitat-demo              # sense/help ALLOW; irreversible + sell DENY

Plain story for anyone: docs/ECOSYSTEM-PLAIN.md (site: Place care (plain)).

Open on your phone (S11) — no store gate

In everyday words: Open a link → you’re in the living place — all of daily life with
people, AIs, and robots together. Pin it to your home screen. Get a clear yes/no when
something serious needs your care. Not a feed, chat, bank, or workplace. No App Store
or Play review required — ever. Stores may wrap later as optional adapters; the habitat
door is the browser (PWA).

  1. On your phone browser, open: https://www.animasimbiotica.com/presence/
  2. (Until HTTPS cert lands, http://www.animasimbiotica.com/presence/ may work for demos.)
  3. You should see: You, people/pets/places today, your twin & helpers (generic
    invited peers — any twin or care helper can plug in; the habitat is not a rebrand of one app), and Ask me.
  4. Tap Ask me for the guardian yes/no screen (demo mode until your node is wired).
  5. Add to Home Screen:
  6. iPhone Safari: Share → Add to Home Screen.
  7. Android Chrome: menu → Install app / Add to Home screen.

Local narrow-viewport check:

cd site && python3 -m http.server 8080
# then open http://127.0.0.1:8080/presence/ on a phone on the same network
python3 -m refnode version          # expect 0.12.0-sketch after twelfth seal
python3 -m refnode interop-tests    # S10 / prior stay green

Plain story: docs/PHONE-PRESENCE.md, docs/PRESENCE-SHELL.md.

Presence deepen (S12) — world door

In everyday words: Open presence and you’re in a world — today’s life stream
(people, pets, places, helpers), invite a twin/AI/robot as a peer, share with an optional
grant sketch, and Ask me for serious steps. Optional: point at your local refnode so Ask me
can post a challenge sketch. Not a super-app clone — everything-layer for every kind of mind.

  1. Open https://www.animasimbiotica.com/presence/ (or local site server).
  2. See Today’s life stream care cards; tap Invite helper / Share / Ask me.
  3. Optional node: enter http://127.0.0.1:7401 (or your serve URL) → Save node hook.
  4. Ask me uses demo mode until the node answers /anima/health; then Yes/No posts to /anima/event.

Deepen presence (S12) — day, invite, share, Ask me→node

In everyday words: Open presence and you see today’s care cards (people, pets, places,
helpers). Invite a twin or helper as a peer. Share what matters as a local event (optional
grant). Ask me still gives clear yes/no — and when you set a reference-node URL, it can
post a challenge sketch to your node.

  1. Open https://www.animasimbiotica.com/presence/ (Earth hero must stay).
  2. Scroll Today · care stream — demo cards for place / pet / person / helper.
  3. Tap Invite helper → pick twin/AI/robot/care tool → peer appears in your world.
  4. Tap Share → local share event (+ optional grant sketch). With a node URL, tries POST /anima/event.
  5. Optional: paste a node base URL (e.g. http://127.0.0.1:7401) → Save node → Ask me probes /anima/health.
  6. Tap Ask me → yes/no; when node reachable, posts a consent.challenge.response sketch.
cd site && python3 -m http.server 8080
# phone: http://<lan-ip>:8080/presence/
python3 -m refnode version          # expect 0.12.0-sketch
python3 -m refnode interop-tests    # S7–S10 stay green
