Signed events (v0.2 target)

Status: Hardening plan. Local offline loop may stay unsigned; untrusted federation requires signatures.
Companions: EVENT-AND-CONSENT.md, NODE-BINDING.md

1. When signatures are required

Context sig
Single-operator offline tick optional
Bond across trust boundary required
consent.revoke, bond.exit required
Guardianship grants / challenges required

2. What is signed

Canonical bytes of the event without the sig field:

  1. UTF-8 JSON with sorted keys, no insignificant whitespace (JCS-style; pick RFC 8785 when implementing).
  2. Sign with emitter NodeId private key (ed25519).
  3. Put detached signature in sig as base64url (v0.8 lock; multibase later if needed).
{
  "id": "evt-...",
  "ts": "...",
  "kind": "actuation",
  "emitter": "did:key:z...Node",
  "subject": "did:key:z...Being",
  "payload": {},
  "consent_context": "grant-...",
  "sig": "base64url..."
}

3. Verification

  1. Resolve emitter NodeId → verification key (did:key multicodec).
  2. Confirm active NodeBinding(emitter → subject) when subject is a BeingId.
  3. Verify signature over canonical bytes.
  4. Confirm consent_context grant still active if kind is gated.
  5. Fail closed.

4. Replay & clocks

  • Reject duplicate id from same emitter (store seen ids per peer).
  • Soft clock skew window (e.g. ±5 minutes) for v0.2; harden later.
  • Revokes ignore skew convenience — process immediately if sig valid.

5. Non-goals (yet)

  • Threshold multisig councils
  • Chain anchoring
  • Vendor notaries as trust root

Transparency without authenticity is theater. Sign across trust boundaries.

7. Replay cache (S4.3)

Each node keeps a bounded set of seen (emitter, event_id) pairs.

  • Duplicate id from same emitter → reject (replay).
  • Default retention: 10k entries (prune oldest by mtime; documented in reference-node/README.md).
  • Persist under REFNODE_HOME/seen/ so restarts still fail closed.

8. Clock skew (S4.3)

  • Default accept window: ±5 minutes vs local UTC for inbound signed events.
  • consent.revoke / bond.exit / consent.challenge.response: still verify sig first; skew may be looser for revoke (v0: same ±5m, log warning).
  • Configurable via env ANIMA_SKEW_SECONDS (default 300).

Builder: python3 -m refnode replay-demo — deliver same event twice → second reject; skew-tampered ts → reject.

Builder status (S4.3): refnode/seen.py + skew via ANIMA_SKEW_SECONDS; wired in verify_inbound before apply; python3 -m refnode replay-demo.
