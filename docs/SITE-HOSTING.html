Site hosting (truth homepage)

Artifact: projects/anima-simbiotica/site/ (static HTML).
Domain: www.animasimbiotica.com (and apex if desired).
Rule: Hosting is a disposable adapter. It is not identity, memory, or consent spine.

Why not GoDaddy Website Builder

Website Builder products often cannot publish arbitrary static trees. That is a product limitation, not a reason to rewrite ANIMA as a captive page builder site.

DNS at GoDaddy (or anywhere) can still point the domain at a real static host.

Acceptable v0 hosts (examples)

Host Notes
GitHub Pages Fine for docs; auth to publish is operator glue
Cloudflare Pages / Netlify / sourcehut pages Same class
Any S3/R2 + CDN Same class
Self-hosted nginx on operator hardware Best long-term alignment

None of these become BeingId. Swap hosts without changing protocol docs.

DNS sketch

  1. Publish site/ to the static host.
  2. CNAME www → host instructions (or ALIAS/ANAME for apex).
  3. HTTPS via host or CDN.
  4. Keep canonical link https://www.animasimbiotica.com/ in index.html.

Anti-capture

  • No “Sign in with GitHub” as ANIMA identity.
  • No mandatory account to read the constitution.
  • If the host dies, protocol docs in-repo/docs/ remain source of truth; re-publish elsewhere.

Builder

Continue GitHub Pages (or equivalent) + DNS. HTML from markdown can lag; homepage + core docs first.
