Non-negotiable stack rules

  1. Many nodes; no single kill switch.
  2. Many AIs; no megabrain.
  3. Sovereign keys & memory; real exit (EXPORT-AND-EXIT.md).
  4. Inspectable bonds (THREAT-MODEL.md).
  5. Protocol free forever; money only on edges (COMPUTE-MESH.md late).
  6. Not a company freight stack.
