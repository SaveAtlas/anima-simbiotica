Federation — peers & bonds (v0)

Status: Architecture principles + object sketches.
Companions: PROTOCOL.md §6, EVENT-AND-CONSENT.md, REUSE-VS-INVENT.md
Rule: Opt-in peering. No single relay, no megabrain, no mandatory discovery landlord.

1. What federation means here

Federation is many sovereign nodes choosing to bond — not automatic absorption into one graph owned by one firm.

  • Humans, AIs, robots, guardian-proxied animals/ecosystems may peer.
  • Discovery helpers are FederationHints — disposable.
  • A2A-like Agent Cards and DID-rooted adverts are welcome patterns; no vendor agent cloud is required to exist.

2. Objects

Peer

{
  "being_id": "did:key:z...",
  "endpoints": ["https://node.example/anima", "anima+mqtt://..."],
  "agent_card": { "capabilities": ["sense", "remember"], "protocol": "anima", "version": "0.1.0-sketch" },
  "transports": ["https", "quic"],
  "note": "Endpoints are adapters; identity is the DID."
}

Bond

A consented relationship — the unit of progress.

{
  "id": "bond-<id>",
  "type": "Bond",
  "parties": ["did:key:z...A", "did:key:z...B"],
  "status": "offered | active | exiting | exited",
  "grants": ["grant-...", "grant-..."],
  "streams": ["stream-observations-minimal"],
  "exit_terms": {
    "export": true,
    "delete_replicas": "best_effort",
    "notice_hours": 0
  },
  "created_at": "2026-09-05T03:00:00Z"
}

FederationHint (optional)

{
  "type": "FederationHint",
  "hint_url": "https://relay.example/hints/...",
  "landlord": false,
  "note": "If this dies, peers with bonds still speak DID-to-DID."
}

If removing the hint breaks identity or memory → it was illegally promoted to spine.

3. Lifecycle

  1. Discover (optional hint or out-of-band) → fetch Agent Card / capability advert
  2. bond.offer event — proposed grants + streams + exit terms
  3. bond.accept — both sides persist Bond + grants
  4. Exchange events only under grants
  5. bond.exit — revoke grants, export, stop actuation claims

No accept → no bond. No silent graph join.

4. Transports (adapters)

HTTPS, QUIC, MQTT, ROS2 bridges, etc. live under transport adapters. The bond and DIDs outlive any one pipe.

Reuse:

  • A2A task/message patterns for agent↔agent
  • MCP only for tools inside a node (vertical), not as federation identity
  • AT Proto portability ideas for export bundles

5. Anti-capture tests

Test Must pass
Kill relay X Existing bonds still work via direct endpoints or other hints
Remove Sign-in-with-Y BeingId unchanged
Refuse megabrain API Node still runs local loop
One peer exits Other peer loses grant, not the exiting being’s keys

6. Out of scope for v0 runtime

  • Global reputation scores
  • Mandatory chain anchoring
  • Cross-world habitat mesh economics (see later compute-mesh notes in REUSE-VS-INVENT)

7. Builder next (non-blocking)

  1. Persist Bond JSON beside grants in reference-node
  2. Emit bond.offer / bond.accept / bond.exit locally (single-process sim of two parties)
  3. Keep all discovery code under adapters/

Many small honest links. No single switchboard.
