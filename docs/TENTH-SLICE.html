Tenth slice — architecture plan

Prerequisite: Ninth slice offline sealed (0.9.0-sketch).
Voice: Living ecosystem. Plain words. Invitation first. Not constitution-first.
Story: One place in nature (watershed / habitat / garden) under care — beings and helpers share what’s needed to look after it together.

Goals (plain)

  1. A place can sit at the ANIMA table (through sensors + a caring human).
  2. People, AIs, and robots can help that place — share readings, warn, act carefully.
  3. Serious changes to the place need a clear yes from the guardian.
  4. A non-tech person gets it from one plain page.
  5. Same living-world feel as the public site — habitat, not manifesto.

Goals (builders)

  1. Harden habitat / ecosystem demo path (sense ALLOW; irreversible DENY without challenge).
  2. ECOSYSTEM-PLAIN.md + site render; link from plain words / homepage lightly.
  3. Signed guardian challenges for habitat high acts (ANIMA_SIGN=1).
  4. Interop S10.*; VERSION 0.10.0-sketch when green.
