ADR-002 — Deny unknown action_class

  • Status: Accepted
  • Date: 2026-09-04
  • Deciders: Anima Architect (Ovie veto after review)

Context

ConsentGrant uses dotted action_class strings. Open-ended strings invite “oops, allow everything” bugs and adapter smuggling.

Decision

  1. Unknown action_class → deny (fail closed).
  2. Registries of known classes live in docs / code allowlists per implementation.
  3. New classes require a doc bullet (EVENT-AND-CONSENT conventions or ADR) before production bonds.
  4. Wildcards in guardian action_classes_forbidden are allowed; wildcards in action_classes_allowed must be explicit and narrow (prefer lists).

Consequences

  • Safer default for robots/habitats.
  • Slight friction when experimenting — use local.* for demos.
  • Aligns with threat model “over-actuation” control.

Reference-node

find_active_grant already matches exact class; keep it exact. Do not add * allow matches in spine.
