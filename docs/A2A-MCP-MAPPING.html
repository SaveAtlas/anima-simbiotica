A2A & MCP mapping — adapters, not spine (v0)

Companions: REUSE-VS-INVENT.md, FEDERATION.md, PROTOCOL.md §7
Rule: Steal patterns. Never let big-tech or cloud agent products become identity or memory landlords.

1. Layer cake

Layer Protocol ANIMA role
Tools / context inside a node MCP Vertical adapter — how this agent reaches local tools & data
Agent ↔ agent tasks A2A-like Horizontal peer dialect — capability cards, task lifecycle
Open-web DID federation ANP-like / DID-first Align discovery with BeingId, not enterprise tenants
Consent, custody, multi-being ANIMA Spine — invent here

MCP does not federate beings. A2A does not replace ConsentGrant. ANIMA wraps both.

2. What we reuse from A2A

A2A idea ANIMA use
Agent Card / well-known capability advert identity/agent-card.json rooted in BeingId/NodeId
Task lifecycle (submit, work, complete) Optional peer dialect inside a Bond
JSON-RPC / HTTP transport Transport adapter under adapters/transport
Opaque agent collaboration Fine — still gated by grants

What we do not reuse as spine: vendor-hosted agent engine as the only place cards live; enterprise IdP as BeingId.

3. What we reuse from MCP

MCP idea ANIMA use
Tools & resources for a model decide / local tooling inside one node
Host/client separation Operator-controlled host

What we do not reuse as spine: MCP session as identity; remote MCP over mandatory cloud as memory store.

4. Robot buses

Bus ANIMA use
ROS 2 Robot adapter; actuation still needs ConsentGrant
MQTT / DDS Event transport adapter
Matter / local home Prefer local; cloud bridge = vendor adapter

5. Adapter purity (repeat)

Spine modules (identity, consent, events, loop) must not import:

  • A2A client SDKs that hardcode a cloud
  • MCP hosts that require a landlord login
  • ROS/cloud bridges

Those live under adapters/ and fail the purity test if removing them kills BeingId or local memory.

6. Builder guidance

  1. Keep Agent Card DID-rooted (already sketched).
  2. If adding A2A HTTP dialect, put it in adapters/transport/a2a/.
  3. If adding MCP tool host, put it in adapters/llm/ or adapters/tools/ — never in consent/.
  4. Document every new adapter in adapters/README.md with a one-line “spine impact: none.”

Interop without capture.
