Export & real exit (v0)

Companions: CONSTITUTION.md rights, PROTOCOL.md consent, EVENT-AND-CONSENT.md, FEDERATION.md
Rule: Leave with yourself. Hostage data is a protocol violation.

1. What “real exit” means

When a being exits a Bond, peer, or implementation:

  1. Processing and actuation stop claiming that being.
  2. Grants involving that peer are revoked.
  3. An ExportBundle the being is entitled to is produced.
  4. Replicas are deleted or tombstoned best-effort per exit terms — convenience is not a defense for keeping a silent fork of someone’s past.

Social graph loss may sting. Key and memory hostage must not.

2. ExportBundle

{
  "id": "export-<id>",
  "type": "ExportBundle",
  "being_id": "did:key:z...",
  "created_at": "2026-09-05T04:30:00Z",
  "from_peer": "did:key:z...PeerOrNull",
  "format": "anima.export.v0",
  "contents": {
    "identity": { "being_id": "did:key:z...", "node_bindings": [] },
    "memory_slices": [],
    "grants_issued": [],
    "grants_held": [],
    "bonds": [],
    "event_receipts": [],
    "guardian_links": []
  },
  "integrity": {
    "manifest_hash": "<sha256 hex of contents>",
    "sig_being": "<base64url ed25519 Being sig>"
  },
  "note": "Operator may omit slices they choose not to take; peers must not omit what exit_terms promised."
}

Integrity (S5.2)

On bond.exit / export, the reference-node fills:

  1. integrity.manifest_hash — SHA-256 hex of canonical JSON of contents
  2. integrity.sig_being — Being ed25519 signature (base64url) over the canonical ExportBundle with sig_being omitted

Verify with refnode.bond.verify_export_bundle(bundle, being_public_key). Tampering contents (or the sig) fails closed.

Memory slices

Each slice is a portable object with data_class, created_at, source_node, and bytes or content-addressed pointer. Prefer local files in v0 (remember/store dump) over mandatory IPFS.

3. Exit sequence

  1. Emit bond.exit (signed when cross-trust).
  2. Revoke grants tied to that bond.
  3. Build ExportBundle.
  4. Deliver bundle to being-controlled channel (local path, QR, encrypted blob).
  5. Peer marks bond exited; further actuation with that consent_context → deny.
  6. Best-effort replica purge; log failures transparently.

4. Reference-node v0 → v0.2

Step Action
E1 refnode/exit.py — assemble bundle from local store + grants + bindings
E2 CLI: python -m refnode exit [--peer PEER] writes exports/export-<ts>.json
E3 Bond sim calls exit path
E4 README documents “steal my node → revoke binding → still export being”

5. Non-goals

  • Perfect global erasure (physics says no) — honest best-effort + transparency
  • Charging for exit
  • Exit that requires a vendor cloud account

Exit is a feature of freedom, not a support ticket.
